# Core/Logger

## 목적
`import SolSolCore`를 통해 앱 전체에서 사용 가능한 구조화된 로깅 유틸리티.

## 주요 파일

| 파일 | 설명 |
|------|------|
| `Log.swift` | 정적 메서드를 가진 `Log` 열거형: `Log.d(...)` (디버그), `Log.e(...)` (에러) 등 |

## AI 에이전트 가이드

### 이 디렉토리에서 작업할 때
- 디버그에는 `Log.d("메시지")`, 에러에는 `Log.e("메시지")` 사용 — `print()` 직접 사용 금지
- 코디네이터 생명주기(`"\(self) Start"`)와 DB 작업 모두 이 유틸리티로 로깅
- 로그 호출은 Xcode 콘솔에서 확인 가능; 프로덕션 빌드에서는 로그 레벨 필터링 고려
